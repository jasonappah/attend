# Getting started

Run `bun install` and `bun dev`, then visit the local app. In development, use **Login as Demo User** to explore sample classes.

Add a private Google Calendar iCal URL on the Courses tab. Sync rooms first, then sync courses. A resync can remove unmarked sessions no longer in the calendar; recorded attendance is kept. Mark attendance on Today or History; on the web you can also review and import estimates from a Google Timeline JSON export.

For setup, migration, and deployment notes, see the repository README.
